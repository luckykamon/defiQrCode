# Back defiQrCode

### 1. Fichier environnement

A nommer .env à la racine du dossier `back`


| Nom               | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              | Exemple                                                                                                              |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| MONGO_URI         | Url de la base de données.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              | mongodb+srv://user:password@clusterName.mongodb.net/collection                                                       |
| PASSWORD_DEFI     | Mot de passe admin pour modifier n'importe lequel des défis et les valider.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             | 4JtYXtaVZXrBAVkt7Zbs3zUvo2vn                                                                                         |
| PORT              | Port utilisé par l'application avec npm start. Facultatif, 4011 par default.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            | 4011                                                                                                                 |
| URL_FRONT         | Url du front.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            | http://localhost:4010                                                                                                |
| EMAIL_TRANSPORTER | Facultatif. Configuration du serveur mail pour l'envoie de mails au format stringify d'un objet.<br /><u>host</u>: Adresse du serveur sortant SMTP de l'adresse mail.<br /><u>port</u>:Il s'agit du port du serveur de messagerie à utiliser pour l'envoi d'e-mails. Les valeurs courantes sont `465` pour les connexions sécurisées (SSL) et `587` pour les connexions non sécurisées (TLS).<br /><u>secure</u>: Cette option indique si la connexion doit être sécurisée ou non. Si elle est définie sur `true`, la connexion sera sécurisée par SSL. Si elle est définie sur `false`, la connexion sera sécurisée par TLS. SSL est généralement utilisé avec le port `465`, tandis que TLS est utilisé avec le port `587`.<br /><u>auth.user</u>: Ceci représente le nom d'utilisateur à utiliser pour l'authentification sur le serveur de messagerie.<br /><u>auth.pass</u>: Ceci représente le mot de passe à utiliser pour l'authentification sur le serveur de messagerie. | `'{"host":"SMTP_SERVER","port":465,"secure":true,"auth":{"user":"username","pass":"<P0=2C:&x@Dr=mb8bp*NWp4[v.qx"}}'` |
| EMAIL_OPTIONS     | Facultatif. Configuration de l'adresse mail d'envoie et de réceptionau format stringify d'un objet.<br /><u>from</u>: adresse mail qui envoie les mails via le serveur.<br /><u>to</u>: adresse mail de l'administrateur pour valider les défis qui recevra la clé `PASSWORD_DEFI`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    | `'{"from":"serveur@serveur.com","to":"admin@admin.com"}'`                                                            |

### 2. Installation

```shell
npm i
```

### 3. Run en développement

```shell
npm run dev
```

### 4. Run en production

```shell
npm start
```
