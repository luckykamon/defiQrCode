# Front defiQrCode

### 1. Fichier environnement

A nommer .env à la racine du dossier `front`


| Nom                | Description                                                                  | Exemple               |
| ------------------ | ---------------------------------------------------------------------------- | --------------------- |
| REACT_APP_URL_BACK | Url de l'API.                                                                | http://localhost:4011 |
| PUBLIC_URL         | Chemin de base public de votre application.                                  | /                     |
| PORT               | Port utilisé par l'application avec npm start. Facultatif, 3000 par default | 4010                  |

### 2. Installation

```shell
npm i
```

### 3. Run en développement

```shell
npm start
```

### 4. Build en production

```shell
npm run build
```
